# 《灰烬王冠：沉眠墓城》世界设定

## 核心设定

灰历 317 年，维尔王朝已经消失三百年。官方史书把它的灭亡归因于瘟疫，但边境人知道另一种说法：末代国王赫里昂在“第十三钟”响起之前，把自己的名字、王权与灵魂一起铸进灰烬王冠，将整座首都维尔变成了一座巨大的封印。

封印的对象没有名字。旧王朝只称其为“门后的东西”。

三百年来，墓城里的死者没有真正复活。他们被灰烬王冠固定在生命最后几分钟的记忆中，一遍又一遍地巡逻、逃亡、祈祷、杀戮。如今这种循环开始出现裂缝：亡者走出了原本的房间，旧王庭的钟重新响起，而巡夜团的斥候接连失踪。

玩家收到一封没有署名的信：

> 在第十三次钟鸣之前进入王墓。不要相信王冠，也不要急着憎恨国王。

## 三个公开势力

- **巡夜团**：驻守墓城外围的边境组织。职责是记录异变、阻止盗墓者并确保“钟不会响到第十三声”。
- **灰烬教团**：相信赫里昂找到了永生方法。他们试图夺取王冠，但并不知道所谓永生其实是无法结束的记忆循环。
- **无脸商会**：跨越战争和灾区做生意的中立商人。没人知道他们为什么能进入墓城，也没人见过面具下的脸。

## 玩家在首个 Campaign 中可发现的真相

1. 灰烬王冠不是统治工具，而是一把“门闩”。
2. 赫里昂不是单纯的暴君。他把自己变成封印的一部分，因此三百年无法真正死亡。
3. **失落王印**与赫里昂的真名，是改变封印而非单纯摧毁它的关键。
4. 游戏首版的 Boss 胜利存在普通结局与“理解真相 + 持有王印”触发的更完整结局。

## 美术基调

- 低饱和石灰、铁锈、旧金、冷蓝灰。
- UI 不采用现代后台管理风格；尽量像一本会发光的探险记录册。
- 场景采用 2.5D 思路：背景 SVG + 雾效 + 光照 + 实体/NPC 图层。

## V0.3 可探索区域

墓城不再只是一条墓穴走廊，而被拆成多个拥有自己历史痕迹的城区：

- **外墓区**：断碑、墓廊与巡夜团最后留下的补给。
- **悼亡礼拜堂**：用于纪念“被抹去姓名的人”，无面圣像仍守着逆流的蜡泪。
- **王庭焚书馆**：大多数档案被主动焚毁，只剩几份银线卷宗记录封印前七日。
- **沉水钟厅**：第二声钟来自黑水之下，没有人能找到真正的敲钟者。
- **旧王囚室**：关押的不是普通罪犯，而是参与制造王冠与十三道锁链的工匠。
- **灰玫瑰庭**：王后塞琳留下的地下花园，花会记住触碰者的体温。
- **千骨堂**：不同年代的遗骨被重新排列成占卜装置。
- **冷炉工坊**：仍会自行运转的王庭铸造设施，保存着关于“王冠其实是锁”的证据。
- **地下观测台**：星仪映出的不是天空，而是会变化的墓城结构。
- **最后宴厅**：亡者重复王朝最后一夜的庆典，永远等不到真正的第十三声钟。
- **王名密室**：默认不存在于玩家地图中，需要通过世界机关发现；这里保存被公开历史删除的名字。
- **灰疫医馆**：封存着瘟疫时期被刻意改写的病历，药柜需要抄写员印章。
- **折冠门楼**：旧王城防线的机械门楼，巡夜徽章能开启遗留储物柜。
- **黑水引渠**：可操作水闸改变环境状态，排水后才会暴露新的搜寻目标。
- **断月桥**：跨越墓城深裂隙的断桥，需要敏捷检定才能安全通过。
- **灰烬审判庭**：保存最后一批判决与审判官封存箱。
- **无钟之塔**：钟早已被拆走，但驱动机构仍连接着墓城深层结构。
- **王室封藏间**：通过星仪 / 无钟之塔等条件链发现，王印能开启真正的王室封藏物。
- **白石王陵**：被世界钟声和骨钥匙共同限制的深层王陵。

这些区域的差异不仅存在于文字描述。每个区域对应独立场景背景和场景元素，调查结果会进入 Lore、Flag、Quest、Inventory 或 Map State。
