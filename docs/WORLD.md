# 《灰烬王冠：沉眠墓城》V0.4 世界设定

## 核心设定

灰历 317 年，维尔王朝已经消失三百年。官方史书把它的灭亡归因于瘟疫，但边境人知道另一种说法：末代国王赫里昂在“第十三钟”响起之前，把自己的名字、王权与灵魂一起铸进灰烬王冠，将首都维尔变成了一座巨大的封印。

墓城里的死者并非真正复活，而是被固定在生命最后几分钟的记忆中，重复巡逻、祈祷、逃亡与杀戮。玩家最初会以为灰烬王冠就是整个灾难的核心，但 V0.4 将真相推进到墓城之外：

> 维尔并不是封印本身，而只是钉住封印的一枚“王钉”。

赫里昂用自己和整个王朝把某种东西压在世界边界上。王冠开始失效后，墓城只是最先出现裂缝的地方。

玩家收到一封没有署名的信：

> 在第十三次钟鸣之前进入王墓。不要相信王冠，也不要急着憎恨国王。若王座后的风开始吹，就继续往东。

## 三个公开势力

- **巡夜团**：驻守墓城外围的边境组织，记录异变并阻止钟声推进。
- **灰烬教团**：误以为赫里昂找到了永生，试图夺取王冠。
- **无脸商会**：跨灾区活动的中立商人，对墓城与荒原的道路似乎知道得过多。

## ACT I · 沉眠墓城

玩家在墓城中逐步发现：

1. 灰烬王冠不是统治工具，而是一把门闩。
2. 赫里昂不是单纯暴君，他本人就是锁链的一部分。
3. 失落王印、赫里昂的真名与王庭十三道锁链共同决定封印形态。
4. 击败赫里昂并不会终止异常，反而会扯断墓城最后一道王冠锁链。

主要城区包括外墓区、悼亡礼拜堂、王庭焚书馆、沉水钟厅、旧王囚室、灰玫瑰庭、千骨堂、冷炉工坊、地下观测台、最后宴厅、王名密室、灰疫医馆、折冠门楼、黑水引渠、断月桥、灰烬审判庭、无钟之塔、王室封藏间和白石王陵。

## ACT II · 雾外荒原

赫里昂倒下后，王座后的石门裂开，墓城第一次吹进真正的风。门外不是正常地表，而是一片被封印扭曲了三百年的荒原。

### 雾外界碑

刻着“维尔以东没有国土”的旧界碑。碑文背面却留下另一句手刻文字：这里不是边界，是第二道门闩。

### 灰风平原

风里混着墓城灰烬，但流向与现实风向相反。巡夜团认为这里的风不是空气，而是某种从封印缝隙里泄出的“时间方向”。

### 停滞商队

整支车队停在同一秒钟：篝火没有熄灭，倒下的人没有继续腐败。商队日志透露无脸商会早就知道墓城之外还有另一层封印。

### 镜砂洼地

黑色玻璃沙会储存声音。踩碎一片镜砂，可能听见数十年前某个陌生人的最后一句话。

### 坠星裂谷

裂谷中央存在不属于当地地质的星体残片。坠星材料可以锻成对封印构装格外有效的星钢武器。

### 反向观测台

望远镜不是看向天空，而是看向地底。这里保存通向最终黑门所需的「虚空罗盘」。

### 无像风祠

没有神像，只有被风磨出的空座。风誓者认为名字会成为门的把手，因此拒绝给神留下名字。

### 陨铁采掘场

旧王朝在这里秘密开采坠星铁，用于铸造王冠与封印器具。

### 无旗骑士营

一支拒绝继续为王朝效忠、却仍选择守门的骑士残部。他们死后仍维持阵地，因此被后世史书彻底抹去。

### 逐风营火

荒原上少数不会被逆风吹灭的火。可作为第二幕的休整点。

### 外封印黑门

真正的“门”。虚空罗盘能指出门上不存在于肉眼中的锁线；意志不足的人会把自己的记忆误认为门后的召唤。

### 门后心室

并非传统房间，而是一段被强行塑造成建筑形态的封印内部空间。最终 Boss「门后之心 · 厄涅玛」在这里维持类似心跳的周期性冲击。

## V0.4 可发现的更深真相

1. 墓城只是更大封印结构的一枚“王钉”。
2. 灰烬王冠的作用不是把门永久关上，而是把一次灾难延长成三百年的缓慢失败。
3. 荒原上的风誓、坠星和虚空罗盘来自另一套不依赖王权的封印传统。
4. 最终结局取决于玩家是否理解赫里昂真名、风誓、坠星之力以及封印最后代价，而不是单纯把 Boss HP 打到零。

## 美术基调

### 墓城

低饱和石灰、铁锈、旧金、冷蓝灰；烛火、黑水、骨骼和地下机械构成主要视觉元素。

### 雾外荒原

灰白天空、黑玻璃、暗红坠星裂隙、逆向风沙与孤立火点。画面更开阔，但比墓城更缺乏安全感。

UI 仍保持“会发光的探险记录册”风格；场景使用背景 SVG + 雾 / 风 / 光照 + 实体层 + VFX 层构成 2.5D 表现。
