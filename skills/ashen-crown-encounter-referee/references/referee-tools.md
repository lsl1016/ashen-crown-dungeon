# Encounter referee tools

Read: `inspect_world`, `inspect_room`, `inspect_combat`, `search_catalog`, `recent_log`.

Rule: `roll_check`.

Encounter: `spawn_enemy` (high risk; preview first).

Reward: `grant_item` (high risk; preview first and do not bypass game progression).

The referee does not directly perform player combat actions; those remain normal Game Runtime actions. The referee controls GM-side uncertainty, encounter setup, and exceptional rewards.
