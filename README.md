# 灰烬王冠：沉眠墓城 v0.4.0

一个**完全不依赖 AI 也能运行和游玩的 Dungeon / TRPG 原型**。V0.4 基于 V0.3 继续增量升级，重点从“有战术与 Build”推进到“有双幕战役、角色实体、战斗视觉反馈、Boss 演出和第二个大区域”。

> 当前版本仍未接入任何 LLM。AI DM 的 Tool Boundary 继续保留；游戏规则、地图、战斗、任务、装备和世界事实全部由 Go Game Runtime 管理。

## V0.4 最重要的变化

### 1. 从单墓城扩展为双幕 Campaign

第一幕仍然发生在「沉眠墓城」。但击败烬冠承载者赫里昂后，游戏**不会结束**：王座后的石墙会裂开，地图东侧解锁第二幕「雾外荒原」。

```text
ACT I 沉眠墓城
  → 探索 / 机关 / Build / 世界钟声
  → 烬冠承载者 · 赫里昂（三阶段）
  → 王座后石门开启
  → ACT II 雾外荒原
  → 黑玻璃、灰风、坠星与无旗骑士
  → 外封印黑门
  → 门后之心 · 厄涅玛（三阶段）
  → 多条件最终结局
```

第二幕不是结尾文字，而是真正追加到同一张世界地图中的 12 个地点，拥有独立场景、敌人、事件、关键道具和最终 Boss。

### 2. 场景中出现真正的玩家实体

前端增加场景实体层。玩家角色不再只是左侧属性卡：

- 点击热点后，角色会先移动到目标附近再交互。
- 攻击 / 技能 / 防御 / 受击都有对应动作反馈。
- 进入新区域会出现幕间 / 区域切换演出。
- Boss 入场和 60% / 30% 阶段变化会触发独立遮罩演出。
- 战斗加入斩击、爆发、受击震屏、伤害 / 治疗 / 能量飘字。

这些动画只负责表现，真实数值仍然全部以后端结果为准。

### 3. 第二幕「雾外荒原」

新增 12 个地点：

- 雾外界碑
- 灰风平原
- 停滞商队
- 镜砂洼地
- 坠星裂谷
- 反向观测台
- 无像风祠
- 陨铁采掘场
- 无旗骑士营
- 逐风营火
- 外封印黑门
- 门后心室

新增 12 套对应场景资产，并补充荒原专属 Lore、事件、环境调查和条件机关。

### 4. 第二幕敌人、装备与关键道具

新增敌人：

- 灰风掠夺者
- 镜砂行尸
- 沙丘怨灵
- 天穹吸血虫
- 无旗风暴骑士
- 最终 Boss「门后之心 · 厄涅玛」

新增物品包括：

- 虚空罗盘
- 星钢长刃
- 荒原斗篷
- 镜砂护符
- 瓶装灰暴
- 星辉药膏
- 风誓令牌
- 门后黑晶

其中星钢长刃会对构装类敌人以及重击 / 冲锋 Intent 形成额外压制；瓶装灰暴会实际降低敌人后续攻击能力并消耗一个战斗回合。

### 5. 关键主线防软锁

第二幕关键推进不会因为一次失败骰点永久卡死：

- 反向观测台存在可重试的虚空罗盘获取路径。
- 外封印黑门要求持有虚空罗盘，并进行意志检定。
- 检定失败会触发守门战斗，但不会把机关永久标记为完成，玩家仍可再次挑战。
- 最终心室初始完全锁定，只有真实世界状态满足后才会加入可达地图。

## V0.3 系统仍完整保留

### 意图制战斗

敌人下一回合行动提前显示：普通攻击、蓄力重击、连续突袭、防御、诅咒、汲取、冲锋等。玩家需要根据 `NEXT INTENT` 决定攻击、防御、职业技或战斗道具。

### 角色 Build

三个职业共 **12 个职业天赋**；装备为武器 / 护甲 / 饰品三槽，并真实修改战斗属性。

### 条件式场景交互

SceneElement 支持物品、Flag、隐藏条件、D20 检定、成功/失败效果、环境变化、地图解锁和战斗触发。

### 世界钟声

探索移动持续推进世界钟声与威胁等级，后续敌人的生命 / 防御会随世界变化增强。

## 操作说明

1. 创建角色并选择职业。
2. 开局可点右上角“天赋”，用初始天赋点确定第一项 Build。
3. 场景中发光热点可直接点击，角色会靠近后交互；底部行动区同时保留按钮入口。
4. 条件未满足的机关会直接显示所需物品 / 世界状态 / DC。
5. 地图有脉冲的节点可移动，右侧“附近道路”也可前往。
6. 战斗先观察敌人 `NEXT INTENT`，再选择攻击、职业技、防御或道具。
7. 战斗消耗品会真正消耗一个回合。
8. 击败赫里昂后继续探索，不要把第一幕 Boss 当作最终结局。
9. 第二幕需要收集虚空罗盘并打开外封印黑门，才能进入真正最终 Boss 房。
10. 右上角声音按钮可以关闭 / 打开本地合成音效；`▣` 可手动存档。

## AI 接入原则

后续仍坚持：

> **代码定义能力，数据定义世界，AI 通过 Tool 操纵能力与世界。**

AI 不需要、也不应该在运行时修改 Go / JavaScript 源码。V0.4 新增的双幕、动态解锁、场景实体和演出都建立在结构化 World State 上，未来 DM Agent 只需要解释自由语言并调用现有 Game Tool。
